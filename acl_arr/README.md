# ACL ARR Submission Package

This folder contains the anonymous ACL Rolling Review version of the StealthRL manuscript.

## Build

```bash
tectonic -X compile stealthrl.tex
```

## Notes

- Uses the official ACL review style via `\usepackage[review]{acl}`.
- The manuscript is anonymous and uses the anonymous 4open repository URL.
- The main paper content is intended as a long-paper submission; references, limitations, ethics, and appendices are included in the same PDF.
- ARR/OpenReview generally requires the PDF upload. The LaTeX source is included here for collaborators and reproducibility.
