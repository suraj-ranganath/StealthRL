Architecture

Small public surface, research-grade backend hooks.

01

Bounded access

Unauthenticated users get a persisted daily quota. API keys can be configured with separate daily limits for collaborators, reviewers, or lab demos.

02

Lazy inference

The service starts cheaply. Real StealthRL sampling loads only when the Tinker backend is enabled and a request arrives.

03

Research context

The UI reports text-shape diagnostics and links directly to the paper and model, without presenting detector evasion as a production guarantee.
